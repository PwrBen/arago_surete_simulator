# Arago Sûreté Simulator : Opération VIDOCQ

Une application ludo-pédagogique sous forme de *Serious Game*, spécialement conçue pour s'entraîner et réviser le cadre légal et les méthodes d'intervention de la sécurité privée.

## Comment héberger cette application gratuitement sur GitHub Pages :

1. **Créer un compte GitHub** : Si vous n'en avez pas, inscrivez-vous sur [github.com](https://github.com/).
2. **Créer un dépôt (Repository)** :
   - Cliquez sur le bouton "New" (Nouveau dépôt).
   - Nommez-le `arago-surete-simulator`.
   - Laissez-le en "Public" et cliquez sur "Create repository".
3. **Ajouter les fichiers** :
   - Dans votre nouveau dépôt, cliquez sur "uploading an existing file".
   - Glissez-déposez les fichiers extraits de cette archive (`index.html`, `style.css`, et `script.js`).
   - Cliquez sur "Commit changes" (Enregistrer les modifications).
4. **Activer GitHub Pages** :
   - Allez dans l'onglet **Settings** (Paramètres) de votre dépôt.
   - Dans le menu de gauche, descendez et cliquez sur **Pages**.
   - Sous "Build and deployment" > "Source", choisissez "Deploy from a branch".
   - Sous "Branch", sélectionnez `main` (ou `master`) et laissez le dossier sur `/ (root)`.
   - Cliquez sur **Save** (Enregistrer).
5. **Partager le lien** :
   - Au bout d'une ou deux minutes, rafraîchissez la page des paramètres.
   - Vous verrez un message vert indiquant le lien de votre application (ex: `https://votre-pseudo.github.io/arago-surete-simulator/`).
   - Vous pouvez désormais partager ce lien avec vos élèves pour qu'ils s'entraînent sur leur téléphone ou leur ordinateur !
